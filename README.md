# LaLe — 多模态智能阅读与知识提取 Agent 平台

> 面向外语学习者的沉浸式阅读平台。集成“查词、翻译、语法、术语、短语”等高频工具，通过 ReAct Agent 实现从多模态文件解析到自动化笔记沉淀的完整数据流。

##  项目简介

在传统的外语阅读中，用户往往需要在 PDF 阅读器、词典、翻译软件和笔记应用之间反复切换，导致注意力割裂，且查过的单词、翻译过的长难句难以系统化沉淀。LaLe 致力于解决这一痛点，提供一个“阅读-答疑-沉淀”的一站式闭环体验：

1. **沉浸阅读**：支持 PDF、图片、TXT 等多模态文件，自主实现“手绘框选提取”交互。
2. **智能答疑**：基于大模型的 ReAct Agent，按需调用本地 RAG 与 Web 搜索，提供准确的翻译、语法解析和查词服务。
3. **知识沉淀**：碎片化提问可一键“加入笔记”，并由 Agent 自动进行去重与结构化整合，生成生词本与专属笔记库。

##  核心功能

### 沉浸式阅读交互
1. **多模态文档解析**：支持 PDF / DOCX / 图片 / TXT 格式，后端自动完成解析、分块与入库。
2. **手绘框选提取**：基于 `React-PDF` + `Canvas` 实现透明文本层，解决传统 PDF 划词不准的问题，支持鼠标拖拽画框提取文字，并允许自定义二次修正。
3. **高亮与标注**：阅读过程中的重点内容支持高亮保存。

### Agent 智能答疑 (ReAct)
1. **意图识别与工具调用**：大模型接收用户请求后，自主判断是否需要调用“本地 RAG”（混合检索 + Rerank）或“Web 联网搜索”，增强回答的准确率。
2. **五大核心能力**：查词、翻译、长难句语法解析、术语识别、短语搭配提取。
3. **流式响应**：基于 SSE 实现打字机效果，降低长耗时模型请求的用户等待焦虑。

### 自动化知识管理
1. **碎片笔记整合 Agent**：支持将多条零散笔记（如多个生词、多个语法点）拖拽合并，由 LLM 完成去重与结构化重组，生成一份完整的复习文档。
2. **生词本与笔记库**：支持将查词结果一键加入生词本，支持笔记的增删改查与回收站（软删除，默认保留 15 天）。

### 完善的账户与文件系统
1. **手机号一键登录**：简化注册流程（免验证码），基于 JWT 实现 7 天无感登录状态保持。
2. **物理与软删除**：账户注销支持物理级联删除（数据库记录 + 物理文件）；文档/笔记删除移入回收站。

## 核心技术实现

### 1. Agent 工具调用与推理 (ReAct)
- **实现逻辑**：大模型接收任务后，基于 ReAct (Reasoning + Acting) 范式自主拆解任务。遇到生僻词汇或复杂长难句时，并发调用本地 RAG（混合检索 + Rerank）与 Web 联网搜索工具。
- **工程价值**：解决了单一模型幻觉问题，提高了“翻译”与“长难句语法解析”的准确率和事实性。

### 2. 沉浸式前端交互设计 (React-PDF + Canvas)
- **痛点**：原生 PDF 划词依赖文本层坐标，扫描件或复杂排版下误差极大。
- **方案**：利用 Canvas 叠加透明文本层，自主设计“鼠标拖拽画框”机制，开发了“手绘框选提取”功能。提取后的文字支持弹窗二次修正，再送入大模型。
- **效果**：彻底解决了 PDF 划词误差，交互更符合人类阅读直觉。

### 3. 高可用后端与性能优化
- **异步与线程池**：使用 FastAPI 搭建 RESTful 服务，针对长耗时的模型推理请求，采用 `run_in_threadpool` 处理，避免阻塞主事件循环。
- **多表级联与生命周期**：结合 PostgreSQL 管理账号、文档、笔记等多表级联生命周期。独立设计了回收站机制（15 天软删除，到期由定时任务清理）。
- **测试覆盖**：通过 Pytest 编写了 65+ 接口的全链路测试，保证核心业务逻辑的稳定性。

### 4. 自动化知识沉淀 (碎片笔记整合)
- 前端支持多条笔记的拖拽合并，后端通过 LLM 对输入的多条笔记进行去重、归类与结构化重组（Markdown 格式）。整合后的笔记自动标记原笔记为已整合状态，避免重复处理。
